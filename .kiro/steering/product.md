# Scholar-Lite Product Overview

Scholar-Lite is a modern, high-performance static website template designed specifically for academic labs and scholars. It provides a zero-configuration solution for creating professional academic websites with automated publication management.

## Key Features

- **Zero-JS Performance**: Built on Astro v6 with 100/100 Lighthouse scores
- **Automated BibTeX Import**: One-command import of publications from `.bib` files
- **Multilingual Search**: Built-in Pagefind search supporting 8 languages
- **Academic Content Management**: Structured content types for publications, team, research, patents, software, and honors
- **Modern Tech Stack**: Astro + React + Tailwind CSS v4 + TypeScript

## Target Users

Academic researchers, university labs, and scholars who need professional websites to showcase:
- Publications and research papers
- Team members and collaborators  
- Research areas and projects
- Academic achievements and honors
- News and activities

## Core Value Proposition

Transforms complex academic website creation into a simple, automated process while maintaining professional appearance and optimal performance.
